
Loi thuc te gap:
#Conflic version
- `golangci-lint` dung ban build bang go1.24.6 trong khi project can Go 1.25.0.

Cac buoc da fix thanh cong (Git Bash / MINGW64):
1. Kiem tra Go:
	- `go version` (phai la go1.25.x)
2. Kiem tra toolchain va duong dan:
	- `go env GOTOOLCHAIN` (auto)
	- `go env GOPATH GOBIN`
	- `where golangci-lint`
3. Xoa ban `golangci-lint` cu:
	- `rm -f "/c/Users/manha/go/bin/golangci-lint.exe"`
4. Cai lai bang Go 1.25.0 (ep toolchain de tranh build bang Go cu):
	- `GOTOOLCHAIN=go1.25.0 GOBIN="$(go env GOPATH)/bin" go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest`
5. Xac nhan lai:
	- `golangci-lint --version` (phai hien built with go1.25.0)

Sau khi xong, chay lai:
- `make dev`

Loi tiep theo gap (GOPATH/GOMODCACHE bi sai do OS env):
- Thong bao: `could not create module cache` hoac `open C:\Users\manha\go \pkg\...` (co khoang trang sau `go`).
- Nguyen nhan: bien moi truong `GOPATH` cua Windows bi set sai (co khoang trang) nen go tao duong dan loi.

Cach fix (Windows):
1. Kiem tra bien moi truong:
	- CMD: `echo %GOPATH%`
	- Git Bash: `echo $GOPATH`
2. Dat lai gia tri dung (khong co khoang trang):
	- CMD:
	  - `setx GOPATH "C:\Users\manha\go"`
	  - `setx GOMODCACHE "C:\Users\manha\go\pkg\mod"`
3. Dong terminal va mo lai, sau do kiem tra:
	- `go env GOPATH GOMODCACHE`
4. Thu lai:
	- `make dev`
